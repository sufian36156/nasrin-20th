## 🌟 ฟีเจอร์หลักในเว็บ

1. **ฉากที่ 1: OTP Unlock (รหัส: `10-10-2549`)**
   - กล่องกรอกรหัส 3 กลุ่ม (วัน 2 - เดือน 2 - ปี 4 หลัก)
   - กระโดดข้ามช่องอัตโนมัติ และรองรับปุ่ม Backspace ถอยหลัง
   - กรอกผิด: กล่องสั่น (Shake) + เสียงเตือนน่ารัก + ข้อความใบ้
   - กรอกถูก: กุญแจปลดล็อก + แสงระเบิด + Confetti พุ่ง + เสียงชัยชนะ

2. **ฉากที่ 2: มินิเกม 4 ด่าน (มีตัวนับเกมที่ 1/4 - 4/4)**
   - **ด่าน 1 (จับคู่การ์ด):** เปิดหาคู่ 4 คู่ จับถูกมีเสียง Chime และเด้งข้อความความทรงจำ
   - **ด่าน 2 (ต่อภาพปริศนา):** แตะสลับ 2 ชิ้นส่วนเพื่อเรียงลำดับให้ครบสมบูรณ์
   - **ด่าน 3 (วงล้อความทรงจำ):** กดปุ่มหมุนวงล้อสีพาสเทล สุ่มเรื่องราวประทับใจ
   - **ด่าน 4 (ควิซทายใจ):** 4 คำถามความสัมพันธ์สุดน่ารัก ตอบอะไรก็ได้รับความรัก 100%

3. **ฉากที่ 3: Photo Avalanche (แกลเลอรีรูปโพลารอยด์)**
   - รูปภาพจัดวางสไตล์โพลารอยด์เอียงมุมสุ่ม พร้อมเทปกาว
   - เลื่อนลงมาเรื่อยๆ มีเสียงกระดิ่งเบาๆ และภาพ Fade-in

4. **ฉากที่ 4: การ์ดจดหมายอวยพรวันเกิด 20 ขวบ**
   - ข้อความอวยพรซึ้งๆ ตกแต่งด้วยประกายและดอกไม้

5. **ฉากที่ 5: เค้กวันเกิด 3D + เป่าเทียน + ลากมีดตัดเค้ก**
   - **เป่าเทียนด้วยไมโครโฟน:** ตรวจจับแรงลมจากไมค์จริง (พร้อมปุ่มแตะสำรอง)
   - **ลากมีดตัดเค้ก:** ลากนิ้ว/เมาส์ผ่านกลางเค้ก เค้กจะแยกเป็น 2 ซีกพร้อมเสียงฉึบ!
   - คอนเฟตตี้ระเบิดใหญ่ฉลองวันเกิด

6. **ส่วนท้าย: คลังวิดีโอ (Video Vault)**
   - Grid รวมคลิปวิดีโอ กดเปิดดูได้ทันที รองรับทั้งลิงก์ YouTube และไฟล์ .mp4

## 🛠️ วิธีแก้ไขข้อมูล / ใส่รูปจริงและคลิปจริง

ไฟล์เดียวที่คุณต้องเปิดแก้ไขคือ **`js/config.js`**:
* **เปลี่ยนชื่อ / วันเกิด:** แก้ตรง `nickname`, `birthdayDateText`
* **เปลี่ยนรหัสผ่าน:** แก้ตรง `secretPasscode`
* **เปลี่ยนรูปโพลารอยด์:** นำรูปภาพของคุณไปวางในโฟลเดอร์ `assets/images/polaroids/` แล้วเปลี่ยนชื่อไฟล์ใน `polaroids: [...]`
* **เปลี่ยนคำถาม / ช้อยส์ / คำสัญญา:** แก้ข้อความใน `quizzes`, `wheelStories`, `memoryCards`
* **ใส่วิดีโอจริง:**
  - *วิธีแนะนำ:* นำคลิปอัปโหลดขึ้น YouTube แบบ **Unlisted (ไม่เป็นสาธารณะ)** แล้วนำลิงก์ Embed มาใส่ตรง `videoUrl`
  - หรือนำไฟล์ `.mp4` ขนาดเบาๆ วางไว้ใน `assets/videos/` แล้วใส่พาทไฟล์

## 🚀 วิธีนำขึ้นอินเทอร์เน็ตเพื่อส่งลิงก์ให้แฟน

### วิธีที่ 1: ใช้ GitHub + Vercel / GitHub Pages (แนะนำที่สุด)
1. อัปโหลดโฟลเดอร์โปรเจกต์นี้ขึ้น Repository ใน **GitHub**
2. ไปที่ **Vercel.com** แล้วกด **Add New Project** -> เลือก GitHub repo นี้
3. กด Deploy เสร็จทันที ได้ลิงก์ฟรี เช่น `https://nasrin-20th.vercel.app` (ส่งให้แฟนได้เลย!)

### วิธีที่ 2: ใช้ Netlify Drop (ลากวางได้ลิงก์ใน 10 วินาที)
1. เปิดเว็บ [app.netlify.com/drop](https://app.netlify.com/drop)
2. ลากโฟลเดอร์โปรเจกต์นี้ทั้งโฟลเดอร์ โยนลงไปในหน้าเว็บ
3. รอ 10 วินาที จะได้ลิงก์เว็บจริงมาส่งให้แฟนทันทีครับ!
